## გაშვება GitHub → Vercel

1. გახსენი ახალი GitHub repository.
2. ამ არქივიდან index.html და vercel.json ატვირთე repository-ს მთავარ დონეზე (არა დამატებით საქაღალდეში). README.md სურვილისამებრ.
3. Vercel-ში დაამატე GitHub repository როგორც ახალი პროექტი.
4. Framework: Other. Root: repository-ს მთავარი დონე. Build command: ცარიელი. Output directory: `.`. vercel.json უკვე შეიცავს ამ კონფიგურაციას.
5. Deploy. ცვლილებები ატვირთე იმავე repository-ში.

Vercel-ის ოფიციალური კონფიგურაციის დოკუმენტაცია: https://vercel.com/docs/project-configuration/vercel-json

## Namecheap დომენის მიბმა

Namecheap არის დომენის რეგისტრატორი; საიტს Vercel უმასპინძლებს.

1. Vercel პროექტის Domains პარამეტრებში დაამატე შეძენილი დომენი და საჭიროების შემთხვევაში www ვარიანტიც.
2. დომენის DNS-ის მართვის ადგილას შეიტანე ზუსტად Vercel-ის მიერ ამ კონკრეტული დომენისთვის ნაჩვენები ჩანაწერები.
3. თუ DNS Namecheap-ში იმართება, ჩანაწერები შეიტანე დომენის Advanced DNS განყოფილებაში. თუ nameservers Cloudflare-ზეა, ჩანაწერები Cloudflare-ში იცვლება.
4. დაელოდე დომენის გადამოწმებას და HTTPS-ის გააქტიურებას. არსებული ფოსტის MX/TXT ჩანაწერები შეინარჩუნე.
